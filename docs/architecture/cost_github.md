# GitHub 月額コスト試算

> 作成日：2026年3月17日  
> 対象プラン：GitHub Enterprise Cloud  
> 料金はすべてUSD表記（税抜）

---

## 前提条件

| 項目 | 設定 |
|------|------|
| ユーザー数 | 3名 |
| Codespaces マシン | 8コア（16 GB RAM） |
| Codespaces 使用時間 | 8時間/日 × 20日 = 160時間/月/人 |
| Codespaces ストレージ | 約10GB/人 |
| Actions ランナー | 標準ランナー（Linux 2コア） |
| Actions 月間使用分数 | 50,000分（無料枠内） |
| Copilot プラン | Copilot Enterprise |

---

## 月額コスト内訳

### GitHub Codespaces

| 項目 | 計算式 | 月額 |
|------|--------|------|
| コンピュート | $0.72/時間 × 160時間 × 3人 | $345.60 |
| ストレージ | $0.07/GB × 10GB × 3人 | $2.10 |
| **小計** | | **$347.70** |

### GitHub Actions

| 項目 | 計算式 | 月額 |
|------|--------|------|
| 実行時間 | 50,000分（無料枠50,000分以内） | $0.00 |
| **小計** | | **$0.00** |

> 50,000分を超えた場合、超過分は $0.006/分（Linux標準）が加算されます。

### GitHub Copilot Enterprise

| 項目 | 計算式 | 月額 |
|------|--------|------|
| ライセンス費用 | $39/人 × 3人 | $117.00 |
| **小計** | | **$117.00** |

---

## 💰 合計

| | 金額 |
|--|------|
| **月額合計** | **$464.70** |
| **年額換算** | **$5,576.40** |

> ※ GitHub Enterprise Cloud 本体（$21/人/月 × 3人 = $63/月）は別途必要 
> ※ Codespacesの実際のアクティブ時間・ストレージ使用量により変動
> ※ Copilotのプレミアムリクエスト超過分（$0.04/リクエスト）は含まれていない
