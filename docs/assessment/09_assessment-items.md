# 評価項目定義書

## 概要

障害者雇用支援アセスメントシステムで使用する評価項目と、スコア基準（行動指標）を定義します。

### 参照元

本評価項目は以下を参考に構成しています。

| 参照元 | 概要 |
|-------|------|
| 障害者職業総合センター（NIVR）「就労支援のためのチェックリスト」（調査研究報告書 No.30） | 3領域34項目の公式チェックリスト。就労移行支援・雇用管理の実務で広く使用される |
| NIVR「就労移行支援のためのチェックリスト」（No.19） | 就労移行段階に特化したチェックリスト |
| 厚生労働省「就労パスポート」 | 障害のある方が職場での支援ニーズを整理するための自己記述ツール |

> **注意：** NIVRの公式チェックリストは○/×形式を採用しており、1〜5スコアの公式統一基準は存在しません。
> 本システムの1〜5スコアおよび行動指標は、NIVR項目を参考にしながら本システム独自に定義したものです。

---

## 1. 共通スコア基準

全評価項目に共通する1〜5スコアの意味を以下のとおり定義します。

| スコア | 基準 | 支援の目安 |
|-------|------|-----------|
| **5** | 自立してできる。支援なしで継続的に安定している | 支援不要。現状維持の確認のみ |
| **4** | ほぼできる。軽微なサポートがあれば安定している | 月1回程度の確認で十分 |
| **3** | 部分的にできる。定期的な声かけ・支援があれば安定する | 週1回程度の支援・声かけが必要 |
| **2** | 課題がある。継続的な指導・支援が必要 | 頻繁（週複数回）な支援が必要 |
| **1** | 大きな課題がある。優先的・集中的な支援が必要 | 毎日の支援・個別対応が必要 |

## 2. 評価項目一覧

### 第1層：健康管理（6項目）

就労の基盤となる身体・精神的な健康状態の自己管理能力を評価します。

---

#### layer1_physical_stability：体調の安定性

| スコア | 行動指標 |
|-------|---------|
| 5 | 体調の波がほとんどなく、毎日安定して活動に参加できている |
| 4 | 月に1〜2回程度の体調不良はあるが、翌日には回復し活動への影響が少ない |
| 3 | 週に1回程度の体調不良があり、活動への参加に影響することがある |
| 2 | 体調不良が週複数回あり、活動の継続が難しいことが多い |
| 1 | 体調が慢性的に不安定で、活動への参加が大幅に制限されている |

---

#### layer1_medication：服薬管理

| スコア | 行動指標 |
|-------|---------|
| 5 | 処方された薬を自分で管理し、毎回正確に服用できている |
| 4 | ほぼ自分で管理できているが、まれに飲み忘れることがある（月1〜2回程度） |
| 3 | 声かけや確認があれば服薬できるが、自己管理には不安が残る |
| 2 | 飲み忘れが頻繁で、体調への影響が出ることがある |
| 1 | 服薬管理が自分ではできず、体調が安定していない |
| N/A | 服薬なし（該当しない場合はスキップ） |

---

#### layer1_medical_visit：通院管理

| スコア | 行動指標 |
|-------|---------|
| 5 | 予約通りに通院し、医師への報告・相談を自分で行えている |
| 4 | ほぼ予約通りに通院できているが、まれに変更・遅延がある |
| 3 | 声かけや送迎サポートがあれば通院できる |
| 2 | 通院を忘れたりキャンセルすることが多く、定期的な支援が必要 |
| 1 | 通院が困難な状態で、医療との連携が取れていない |
| N/A | 通院なし（該当しない場合はスキップ） |

---

#### layer1_sleep：睡眠管理

| スコア | 行動指標 |
|-------|---------|
| 5 | 毎日安定した睡眠が取れており、日中の眠気・疲労感がない |
| 4 | おおむね安定した睡眠が取れており、日中の影響は軽微 |
| 3 | 睡眠が不規則になることがあり、日中に眠気・倦怠感が出ることがある |
| 2 | 睡眠の乱れが頻繁で、日中の活動に支障が出ることが多い |
| 1 | 慢性的な睡眠障害があり、日中の活動がほぼ困難 |

---

#### layer1_meal：食事・栄養管理

| スコア | 行動指標 |
|-------|---------|
| 5 | 3食規則正しく食事ができており、偏りのない食生活が維持できている |
| 4 | おおむね規則正しく食事できているが、まれに食事を抜くことがある |
| 3 | 食事が不規則になることがあるが、声かけがあれば改善できる |
| 2 | 食事を抜くことが多く、栄養バランスが偏っている状態が続いている |
| 1 | 食事管理ができておらず、体調への影響が出ている |

---

#### layer1_disability_understanding：障害・症状の自己理解

| スコア | 行動指標 |
|-------|---------|
| 5 | 自分の障害特性・症状を理解し、困ったときに適切に説明・援助要請できる |
| 4 | 自分の特性をおおむね理解しており、必要時に説明できるが、表現に不安がある |
| 3 | 自分の特性について部分的に理解しているが、他者への説明が難しいことがある |
| 2 | 自分の特性の理解が不十分で、困っていても援助要請できないことが多い |
| 1 | 自分の障害・症状を理解しておらず、支援者側からの働きかけが常に必要 |

---

### 第2層：日常生活管理（5項目）

就労に必要な日常生活の自己管理能力を評価します。

---

#### layer2_life_rhythm：生活リズムの安定

| スコア | 行動指標 |
|-------|---------|
| 5 | 決まった時間に起床・就寝でき、活動日には毎回安定して出席している |
| 4 | 生活リズムはほぼ安定しているが、まれに乱れることがある |
| 3 | 声かけや環境整備があれば生活リズムを維持できる |
| 2 | 生活リズムが乱れがちで、欠席・遅刻につながることがある |
| 1 | 昼夜逆転や不規則な生活リズムが定着しており、活動への参加が難しい |

---

#### layer2_appearance：身だしなみ・清潔保持

| スコア | 行動指標 |
|-------|---------|
| 5 | 清潔感のある身だしなみを毎日自分で整えられている |
| 4 | おおむね清潔な身だしなみができているが、まれに確認が必要 |
| 3 | 声かけがあれば整えられるが、自発的には難しいことがある |
| 2 | 身だしなみが整っていないことが多く、継続的な指導が必要 |
| 1 | 清潔保持ができておらず、他者との関係や就労に支障が出ている |

---

#### layer2_money：金銭管理

| スコア | 行動指標 |
|-------|---------|
| 5 | 収支の把握・管理が自分でできており、計画的に使用できている |
| 4 | おおむね自己管理できているが、まれに確認・相談が必要 |
| 3 | 支援者の確認・助言があれば管理できる |
| 2 | 金銭管理が難しく、計画的な使用ができないことが多い |
| 1 | 金銭管理が自分ではできず、継続的なサポートが必要 |

---

#### layer2_transportation：交通手段の利用

| スコア | 行動指標 |
|-------|---------|
| 5 | 公共交通機関を使って一人で通所・通勤ができている |
| 4 | ほぼ一人で利用できるが、路線変更時など慣れない状況では確認が必要 |
| 3 | 同行・練習があれば一人での利用ができるようになってきている |
| 2 | 交通機関の利用に困難があり、送迎や同行が必要なことが多い |
| 1 | 一人での移動が困難で、常に付き添いが必要 |

---

#### layer2_social_rules：社会的ルールの理解

| スコア | 行動指標 |
|-------|---------|
| 5 | 公共の場・職場のルールやマナーを理解し、自然に守ることができている |
| 4 | おおむねルールを守ることができているが、新しい場面では確認が必要 |
| 3 | 説明・確認があれば守ることができる |
| 2 | ルールを守ることが難しいことが多く、繰り返しの指導が必要 |
| 1 | 社会的ルールの理解が困難で、他者とのトラブルになることがある |

---

### 第3層：対人技能（6項目）

職場での対人関係を形成・維持するためのコミュニケーション能力を評価します。

---

#### layer3_greeting：挨拶・礼儀

| スコア | 行動指標 |
|-------|---------|
| 5 | 場に応じた挨拶・礼儀が自然にできており、周囲から好印象を持たれている |
| 4 | おおむね適切な挨拶ができているが、初対面や緊張場面では不自然になることがある |
| 3 | 促されれば挨拶できるが、自発的には難しい場面がある |
| 2 | 挨拶ができないことが多く、指導が必要 |
| 1 | 挨拶がほとんどできず、対人関係に支障が出ている |

---

#### layer3_communication：会話・コミュニケーション

| スコア | 行動指標 |
|-------|---------|
| 5 | 相手の意図を理解し、適切な言葉・タイミングで会話のやり取りができる |
| 4 | 基本的な会話はできるが、複雑な内容や抽象的な話では理解に時間がかかることがある |
| 3 | 簡単な会話はできるが、複数の情報を含む会話や長い説明の理解が難しいことがある |
| 2 | 会話の理解・表現に困難があり、誤解やすれ違いが生じることが多い |
| 1 | コミュニケーションが著しく困難で、基本的な意思疎通に支援が必要 |

---

#### layer3_reporting：報告・連絡・相談（報連相）

| スコア | 行動指標 |
|-------|---------|
| 5 | 必要なタイミングで自発的に報告・連絡・相談ができている |
| 4 | おおむね報連相できているが、タイミングや内容の判断に迷うことがある |
| 3 | 声かけ・促しがあれば報連相できる |
| 2 | 報連相の必要性は理解しているが、実行することが難しいことが多い |
| 1 | 報連相がほとんどできず、問題が発生しても抱え込んでしまう |

---

#### layer3_cooperation：協調性・チームワーク

| スコア | 行動指標 |
|-------|---------|
| 5 | 他者の立場を尊重しながら協力して作業を進めることができる |
| 4 | おおむね協調できるが、意見の相違時に調整が難しいことがある |
| 3 | 支援者の仲介があればグループ活動に参加できる |
| 2 | 他者との協調が難しく、グループ活動でトラブルが起きることがある |
| 1 | 集団での活動が非常に困難で、個別対応が必要 |

---

#### layer3_emotion：感情コントロール

| スコア | 行動指標 |
|-------|---------|
| 5 | 感情の波を自己認識し、適切に調整・表現することができる |
| 4 | おおむね感情をコントロールできているが、強いストレス時には乱れることがある |
| 3 | 感情が乱れた際に、声かけがあれば落ち着くことができる |
| 2 | 感情のコントロールが難しく、周囲に影響を与えることが度々ある |
| 1 | 感情の爆発・パニック・著しい落ち込みが頻繁で、活動の継続が困難 |

---

#### layer3_assertion：意思表示・自己主張

| スコア | 行動指標 |
|-------|---------|
| 5 | 自分の意見・希望・困りごとを適切に伝えることができる |
| 4 | おおむね伝えることができるが、相手や状況によっては躊躇することがある |
| 3 | 安心できる関係・場があれば意思表示ができる |
| 2 | 意思表示が難しく、我慢したり他者に判断を委ねることが多い |
| 1 | 自分の意思・希望をほとんど表現できず、支援者が汲み取る必要がある |

### 第4層：基本労働習慣（6項目）

職場で継続的に働くために必要な基本的な行動習慣を評価します。

---

#### layer4_attendance：出勤安定性

| スコア | 行動指標 |
|-------|---------|
| 5 | 欠席・遅刻・早退がほとんどなく、安定して出勤できている（月1回未満） |
| 4 | おおむね安定しているが、月1〜2回程度の欠席・遅刻がある |
| 3 | 週1回程度の欠席・遅刻があるが、事前連絡ができている |
| 2 | 欠席・遅刻が週複数回あり、継続的な支援が必要 |
| 1 | 出勤が著しく不安定で、就労の継続が困難な状態 |

---

#### layer4_punctuality：時間管理・スケジュール

| スコア | 行動指標 |
|-------|---------|
| 5 | 作業の開始・終了・休憩時間を自分で管理できている |
| 4 | おおむね時間管理できているが、確認が必要な場面がある |
| 3 | 声かけ・リマインドがあれば時間を守ることができる |
| 2 | 時間管理が難しく、繰り返し声かけが必要 |
| 1 | 時間の感覚・管理が著しく困難で、常に支援が必要 |

---

#### layer4_instruction：指示理解・実行

| スコア | 行動指標 |
|-------|---------|
| 5 | 口頭・文書の指示を正確に理解し、自立して実行できる |
| 4 | 指示をおおむね理解できるが、複雑・複数の指示では確認が必要 |
| 3 | 指示を分解・文書化するなどの工夫があれば実行できる |
| 2 | 指示の理解・実行が難しく、手順書や個別サポートが必要 |
| 1 | 指示の理解が著しく困難で、一緒に行う支援が必要 |

---

#### layer4_concentration：集中力・持続力

| スコア | 行動指標 |

| 3 | 短時間ごとの休憩・声かけがあれば作業を続けることができる |
| 2 | 集中が続かず、頻繁に中断・離席が必要 |
| 1 | 数分程度の作業継続も困難で、個別の配慮・調整が必要 |

#### layer4_accuracy：作業正確性

| 1 | 作業の正確性の維持が著しく困難で、作業内容の見直しが必要 |

#### layer4_rules：職場ルールの遵守

| 3 | 説明・確認があればルールを守ることができる |

### 第5層：職業適性（5項目）

#### layer5_job_fit：職種適性

| 2 | ストレスへの耐性が低く、体調・行動への影響が出やすい |
| 1 | 軽微なストレスでも体調悪化・パニックが起きやすく、環境調整が必須 |

## 4. スコア集計ルール

| ルール | 内容 |
|-------|------|
| 層スコアの計算 | 各層の項目スコアの平均値（小数点第2位で四捨五入） |
| N/A項目の扱い | N/A を選択した項目は集計から除外する（分母から除く） |
| レーダーチャートの表示 | 各層スコア（1.0〜5.0）を5角形のレーダーチャートで可視化する |
| 推奨トレーニングの閾値 | 層スコアが **3.0未満** の層を「支援が必要な層」としてトレーニング提案の対象とする |
