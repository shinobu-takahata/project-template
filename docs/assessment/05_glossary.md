# 用語定義

## 概要

障害者雇用支援アセスメントシステムで使用するドメイン用語・システム用語を定義します。

---

## 1. ドメイン用語

### 対象者・組織

| 用語 | 定義 | 補足 |
|------|------|------|
| 支援対象者 | 障害者雇用支援を受ける当事者。就労移行支援事業所における訓練生、または企業における在籍障害者社員を指す | システムにはログインせず、担当者が情報を管理する |
| 担当者 | 支援対象者のアセスメント・支援計画を実施するスタッフ。就労移行支援事業所の支援員や、企業の障害者雇用担当者が該当する | 組織内で複数の支援対象者を担当できる |
| 組織管理者 | 担当者アカウントの登録・管理と組織情報の設定を行う管理権限を持つユーザー | 担当者ロールも兼ねることができる |
| 利用組織 | システムを利用する事業者単位。就労移行支援事業所または企業の障害者雇用担当部署が該当する | マルチテナントの単位となる |
| 就労移行支援事業所 | 障害者総合支援法に基づき、一般就労を目指す障害者に対して職業訓練・就労支援を提供する福祉サービス事業所 | 利用期間は原則2年以内 |
| 企業障害者雇用担当部署 | 障害者雇用促進法に基づき、障害者の採用・定着支援・合理的配慮を管理する企業内部署 | 継続的な在籍支援が主目的 |

---

### アセスメント

| 用語 | 定義 | 補足 |
|------|------|------|
| アセスメント | 支援対象者の就労に向けた準備状況・能力・課題を体系的に評価する行為 | 本システムでは職業準備性ピラミッドに基づいて実施する |
| 職業準備性ピラミッド | 就労に必要な能力・習慣を5層構造で表したフレームワーク。下層が安定することで上層の能力が発揮されるという考え方に基づく | 障害者職業総合センターが提唱するモデルを参考にしている |
| 第1層（健康管理） | 職業準備性ピラミッドの基盤。体調の安定・服薬管理・通院状況・睡眠・食事管理を評価する | 他の層の前提となる最も基礎的な層 |
| 第2層（日常生活管理） | 生活リズム・金銭管理・交通手段・身だしなみ等、日常生活の自己管理能力を評価する | |
| 第3層（対人技能） | 挨拶・報連相・協調性・対人コミュニケーション等、職場での人間関係形成能力を評価する | |
| 第4層（基本労働習慣） | 出勤安定性・時間管理・指示理解・集中力・持続力等、基本的な就労習慣を評価する | |
| 第5層（職業適性） | 作業能力・就労意欲・職種適性・ストレス耐性等、職業に特化した適性を評価する | |
| 評価スコア | 各評価項目を1〜5の5段階で数値化したもの。1が最も課題あり、5が最も良好な状態を示す | スコアの平均値を層ごとに算出し、レーダーチャートで可視化する |
| 経時変化 | 複数回実施したアセスメントのスコアを時系列で比較すること。支援の効果測定や課題の変化を把握するために使用する | |
| 初回アセスメント | 支援対象者が登録されてから最初に実施するアセスメント | ベースラインとなるスコアを記録する |
| 再アセスメント | 一定期間後に実施する2回目以降のアセスメント。前回との比較・変化の確認が目的 | |

---

### レポート・支援計画

| 用語 | 定義 | 補足 |
|------|------|------|
| 診断レポート | アセスメント完了後に生成される評価結果の可視化ドキュメント。レーダーチャートとスコアサマリで構成される | PDF出力が可能 |
| レーダーチャート | 職業準備性ピラミッド5層のスコアを多角形グラフで表現したもの。今回と前回の結果を重ねて表示することで変化を視覚的に把握できる | |
| トレーニングメニュー | 職業準備性ピラミッドの各層に対応した訓練プログラム。メニュー名・説明・対象層・実施形式・所要時間・達成目標で構成される | 組織ごとにマスタ登録し共有する |
| トレーニング提案 | アセスメントスコアの低い層を自動検出し、対応するトレーニングメニューを推奨する機能 | 担当者は提案を確認した上で実施するメニューを選択する |
| 支援マニュアル | 障害特性・対象場面に応じた支援手順書。マニュアル名・説明・対象障害種別・対象場面・手順・注意点で構成される | 組織ごとにマスタ登録し共有する |
| 個別支援計画 | 支援対象者ごとに作成する支援の方針・内容・期間を定めた計画書。選択したトレーニングメニューと支援マニュアルをもとにシステムが原案を自動生成する | 担当者が編集・確定後にPDF出力できる |
| 合理的配慮 | 障害者差別解消法・障害者雇用促進法に基づき、障害者が働きやすい環境を整えるために事業者が実施する取り組み。個別支援計画に記載する | 法的義務（企業）または努力義務（一部機関）として位置づけられる |
| 個別支援計画原案 | 選択されたトレーニングメニューと支援マニュアルの内容をもとにシステムが自動生成するテキスト。担当者が編集・確定することで正式な計画書となる | |

---

### 障害種別

| 用語 | 定義 |
|------|------|
| 精神障害 | うつ病・統合失調症・双極性障害・不安障害等の精神疾患による障害 |
| 発達障害 | ASD（自閉スペクトラム症）・ADHD・LD（学習障害）等の神経発達的な特性による障害 |
| 身体障害 | 肢体不自由・視覚・聴覚・内部障害等、身体機能の障害 |
| 知的障害 | 知的機能の発達の遅れによる障害 |

## 2. システム用語

### アーキテクチャ

| 用語 | 定義 | 補足 |
|------|------|------|
| テナント | マルチテナント構成における組織単位のデータ分離区画。利用組織ごとにデータが隔離される | 異なる組織のデータは相互参照不可 |
| マルチテナント | 複数の組織（テナント）が1つのシステムを共用しながら、データは組織ごとに独立して管理される方式 | |
| ロール | ユーザーに付与される権限の種類。本システムでは「組織管理者」と「担当者」の2種類を定義する | ロールによって操作できる機能が異なる |
| セッション | ユーザーがログインしてからログアウト（またはタイムアウト）するまでの一連の操作期間 | |
| マスタデータ | 組織内で共有・再利用される基準となるデータ。本システムではトレーニングメニューと支援マニュアルが該当する | |

### 機能

| 用語 | 定義 | 補足 |
|------|------|------|
| 一時保存 | アセスメント入力・個別支援計画編集の途中でデータを保存する機能。完了扱いにならず引き続き編集可能な状態を保つ | |
| 評価完了 | アセスメントの全評価項目入力が完了し、結果を確定する操作。完了後は診断レポートが生成される | |
| 確定 | 個別支援計画の内容を最終版として登録する操作。確定後は履歴として保持される | |
| PDF出力 | 診断レポート・個別支援計画書をPDF形式でダウンロードする機能 | |
| バリデーション | フォーム入力値の整合性チェック。必須項目の未入力・不正な形式・範囲外の値などを検出してエラーを表示する | |
| フィルタリング | 一覧画面において、条件（担当者・障害種別・場面等）で表示対象を絞り込む機能 | |

## 3. 略語・外来語

| 略語・外来語 | 正式名称・意味 |
|------------|--------------|
| ICF | International Classification of Functioning, Disability and Health（国際生活機能分類）。WHOが定める障害・健康状態の分類フレームワーク |
| ASD | Autism Spectrum Disorder（自閉スペクトラム症） |
| ADHD | Attention Deficit Hyperactivity Disorder（注意欠如・多動症） |
| LD | Learning Disability / Learning Disorder（学習障害） |
| PDF | Portable Document Format。電子文書の標準フォーマット |
| UI | User Interface。ユーザーがシステムと接する画面・操作部分 |
| CRUD | Create / Read / Update / Delete。データの基本操作4種 |
