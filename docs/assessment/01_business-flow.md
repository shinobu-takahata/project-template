# 業務フロー図

## 概要

障害者雇用支援アセスメントシステムにおける主要な業務フローを定義します。

---

## 1. As-Is（現状フロー）

### 1-1. 就労移行支援事業所における現状フロー

```mermaid
flowchart TD
    subgraph 担当者
        A1[支援対象者の受け入れ]
        A2[初回面談・情報収集\n- 障害特性・診断名の確認\n- 生活状況・就労経験のヒアリング\n- 本人の希望・目標の確認]
        A3[アセスメント実施\n紙・Excelベース\n- 職業準備性の評価\n- 手動で項目を記録\n- 評価基準がばらつく]
        A4[支援計画の作成\nWord/Excelで個別作成\n- テンプレートの共有が不十分\n- 過去評価との比較困難]
        A5[トレーニングの実施\n- 担当者の経験・知識に依存\n- メニューの体系化・共有なし]
        A6[就職活動・定着支援]
    end

    A1 --> A2 --> A3 --> A4 --> A5 --> A6
```

**現状の課題：**
- アセスメント結果の属人化・ばらつき
- 過去評価との比較・経時変化の把握が困難
- 担当者交代時の引き継ぎコストが高い
- トレーニングメニューの知識共有ができていない
- 個別支援計画の作成に時間がかかる

---

### 1-2. 企業障害者雇用担当部署における現状フロー

```mermaid
flowchart TD
    subgraph 担当者
        B1[障害者採用・配属]
        B2[初期アセスメント\n非公式評価\n- 面談・OJTを通じた評価\n- 評価基準・記録方法が統一されていない]
        B3[配慮事項の特定・調整\n- 本人・主治医・担当者間での口頭確認\n- 合理的配慮の根拠が記録に残りにくい]
        B4[定着支援・フォローアップ\n- 記録が担当者ごとにバラバラ\n- 合理的配慮の見直しが非体系的]
    end

    B1 --> B2 --> B3 --> B4
```

## 2. To-Be（システム導入後フロー）

### 2-1. メインフロー（担当者視点）

```mermaid
flowchart TD
    subgraph 組織管理者
        M1[組織情報を入力]
        M2[担当者アカウント情報を入力]
    end

    subgraph 担当者
        S1[支援対象者の基本情報を入力\n- 氏名・年齢・障害種別・診断名\n- 就労経験・希望職種\n- 担当者のアサイン]
        S2[アセスメントを新規作成]
        S3[職業準備性ピラミッド5層に\n沿って評価入力]
        S4[診断レポートを確認\n- 過去アセスメントとの比較\n- 必要に応じてPDF出力]
        S5[推奨トレーニングを確認・選択]
        S6[支援マニュアルを選択\n- 複数選択可]
        S7[個別支援計画原案を確認・編集\n- 合理的配慮事項を追記\n- 計画書を確定]
        S8[一定期間後に再アセスメントを実施]
    end

    subgraph システム
        P0a[組織情報を保存・管理]
        P0b[担当者アカウントを作成・管理\n初期パスワードをメール送信]
        P1[支援対象者情報を保存]
        P2[入力データを保存・層ごとのスコアを算出]
        P3[レーダーチャートを生成\n前回との差分を比較表示]
        P4[低スコア層を検出し\n推奨トレーニングを提示]
        P5[選択されたトレーニング・マニュアルから\n個別支援計画原案を自動生成]
        P6[前回との変化を可視化・比較表示]
    end

    M1 --> P0a
    M2 --> P0b
    P0b --> S1
    S1 --> P1 --> S2
    S2 --> S3
    S3 --> P2 --> P3
    P3 --> S4
    S4 --> P4
    P4 --> S5
    S5 --> S6
    S6 --> P5
    P5 --> S7
    S7 --> S8
    S8 --> P6
    P6 --> S8
```

---

### 2-2. 利用組織種別による業務フローの差異

| フローステップ | 就労移行支援事業所 | 企業障害者雇用担当 |
|--------------|-----------------|----------------|
| 支援対象者登録 | 訓練生として登録 | 在籍社員として登録 |
| アセスメント目的 | 就職に向けた能力評価 | 現職での適応・配慮評価 |
| トレーニング提案 | 就労移行に向けたスキル習得 | 職場定着・業務遂行支援 |
| 個別支援計画 | 就労移行支援計画 | 合理的配慮計画 |
| 利用期間 | 最大2年（制度上の期限あり） | 継続的（在籍中は継続） |

### 2-3. マスタ管理フロー

```mermaid
flowchart TD
    subgraph 担当者_管理者["組織管理者・担当者"]
        R1[トレーニングメニューの登録]
        R2[支援マニュアルの登録]
    end

    subgraph システム
        P1[マスタとして組織内で共有\n職業準備性ピラミッド各層に紐付け]
        P2[マスタとして組織内で共有\n個別支援計画の原案生成に利用]
    end

    R1 --> P1
    R2 --> P2
```

## 3. 業務フローまとめ

### 主要な業務フローの対応関係

| 業務フロー | 実施者 | システム機能 |
|-----------|--------|------------|
| 支援対象者の受け入れ | 担当者 | 支援対象者登録 |
| アセスメントの実施 | 担当者 | アセスメント実施機能 |
| 評価結果の共有・報告 | システム | 診断レポート出力 |
| 支援方針の検討 | 担当者 + システム | トレーニング提案 |
| 支援手順の決定 | 担当者 | 支援マニュアル選択 |
| 個別支援計画の作成 | 担当者 + システム | 個別支援計画原案作成 |
| マスタ管理 | 組織管理者・担当者 | トレーニングメニュー登録・支援マニュアル登録 |
| 定期的な見直し | 担当者 + システム | 再アセスメント・経時変化表示 |
