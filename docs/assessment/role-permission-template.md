# ロール・権限定義

## 概要

{システム名}におけるロールと操作権限のマトリクスを定義します。

---

## 1. ロール定義

| ロール | 説明 | 主な対象者 |
|-------|------|-----------|
| **システム管理者** | 全組織の登録・管理を行うサービス運営側の特権ユーザー。テナントデータへのアクセス権限は持たない | サービス運営担当者 |
| **組織管理者** | 組織情報・ユーザーアカウントの管理権限を持つ。一般ユーザーとしての全操作も実施可能 | {例: 部門長・管理担当者} |
| **{一般ロール名}** | {説明} | {例: 一般担当スタッフ} |

> {ログインしないユーザー種別がある場合はここに補足}

### ロール間の関係

```
システム管理者
  └─ 組織の作成・管理（全テナントを俯瞰）
     ※ 組織内のデータには原則アクセスしない

組織管理者
  └─ 自組織内の全データを管理

{一般ロール名}
  └─ {アクセス範囲の説明}
```

## 4. 操作制限の詳細

### システム管理者の操作制限

| 制限 | 内容 |
|------|------|
| テナントデータへのアクセス | 組織内データへのアクセス不可。`organization_id` を含まない JWT で制御 |
| 操作対象エンドポイント | `/admin/` プレフィックスのエンドポイントのみ。一般エンドポイントは `403 Forbidden` |
| 物理削除 | 不可。`is_active = false` による論理削除のみ許可 |
