## SC-01: ログイン画面

**目的:** 担当者・組織管理者がシステムにログインする

```
┌─────────────────────────────────────────┐
│                                         │
│          障害者雇用支援アセスメント        │
│                                         │
│  メールアドレス                          │
│  ┌───────────────────────────────────┐  │
│  │ example@org.jp                    │  │
│  └───────────────────────────────────┘  │
│                                         │
│  パスワード                              │
│  ┌───────────────────────────────────┐  │
│  │ ••••••••                          │  │
│  └───────────────────────────────────┘  │
│                                         │
│  ┌───────────────────────────────────┐  │
│  │         ログイン                  │  │
│  └───────────────────────────────────┘  │
│                                         │
│  パスワードをお忘れの方はこちら           │
│                                         │
└─────────────────────────────────────────┘
```

| 項目 | 種別 | 必須 | 備考 |
|------|------|------|------|
| メールアドレス | テキスト入力 | ○ | - |
| パスワード | パスワード入力 | ○ | - |
| ログインボタン | ボタン | - | 認証後はダッシュボードへ遷移 |

## SC-10: アセスメント実施画面

**目的:** 職業準備性ピラミッド5層に沿ってアセスメントを入力する

```
┌──────────────────────────────────────────────────────────┐
│  アセスメント実施: 山田 太郎  2026/03/30                  │
│  進捗: ●●●○○  第3層: 対人技能                           │
├──────────────────────────────────────────────────────────┤
│  [第1層] [第2層] [第3層▼] [第4層] [第5層]               │
├──────────────────────────────────────────────────────────┤
│  第3層: 対人技能                                          │
│                                                          │
│  挨拶・返事                                              │
│  ○1 ○2 ●3 ○4 ○5   [コメント欄               ]          │
│                                                          │
│  報告・連絡・相談                                        │
│  ○1 ○2 ○3 ●4 ○5   [コメント欄               ]          │
│                                                          │
│  協調性・チームワーク                                    │
│  ○1 ●2 ○3 ○4 ○5   [コメント欄               ]          │
│                                                          │
│                    [← 前の層]  [次の層 →]               │
│                    [一時保存]   [評価完了]                │
└──────────────────────────────────────────────────────────┘
```

| 項目 | 種別 | 必須 | 備考 |
|------|------|------|------|
| 層タブ | タブ切り替え | - | 5層を切り替えて入力 |
| 各評価項目スコア | ラジオボタン（1〜5） | ○ | 全項目入力で完了可能 |
| コメント欄 | テキスト入力 | - | 項目ごとの観察コメント |
| 一時保存ボタン | ボタン | - | 途中保存して後から再開可能 |
| 評価完了ボタン | ボタン | - | 全層入力後に活性化。SC-12へ遷移 |

**スコア基準（共通）:**

| スコア | 意味 |
|-------|------|
| 1 | 支援があっても困難 |
| 2 | 継続的な支援が必要 |
| 3 | 部分的な支援で可能 |
| 4 | ほぼ自立しているが配慮が必要 |
| 5 | 自立してできる |

│  [第5層(職業適性):2.8 / 第3層(対人技能):3.0  ... ]      │
│                                                          │
│  ■ トレーニング計画（自動挿入・編集可）                  │
│  ┌────────────────────────────┬──────┬───────────────┐  │

│  └────────────────────────────┴──────┴───────────────┘  │

│                                                          │
│  ■ 特記事項                                              │
│  [                                                    ]  │

| アセスメント結果サマリ | テキストエリア | - | 自動挿入・編集可 |
| トレーニング計画テーブル | テーブル（編集可） | ○ | 選択メニューを自動挿入 |
| 適用支援マニュアル | テキストエリア | - | 選択マニュアルを自動挿入 |
| 合理的配慮事項 | テキストエリア | - | 担当者が手入力 |
| 特記事項 | テキストエリア | - | - |
| PDF出力ボタン | ボタン | - | 確定前でも出力可 |
| 確定ボタン | ボタン | - | 確定後は閲覧専用になる |
