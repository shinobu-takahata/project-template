## エラーケース

| エラーコード | HTTP | 条件 |
|---|---|---|
| `VALIDATION_ERROR` | 400 | リクエスト形式不正（型・必須・フォーマット違反） |
| `{RESOURCE}_NOT_FOUND` | 404 | `{id}` が存在しない |
| `{CONFLICT_ERROR}` | 409 | 競合条件（重複・状態不正など） |
| `UNAUTHORIZED` | 401 | 認証情報が無効 |
| `FORBIDDEN` | 403 | 権限不足 |

```json
// 400 VALIDATION_ERROR
{
  "error": { "code": "VALIDATION_ERROR", "message": "エラーメッセージ" }
}

// 404 {RESOURCE}_NOT_FOUND
{
  "error": { "code": "{RESOURCE}_NOT_FOUND", "message": "リソースが見つかりません: {id}" }
}

// 409 {CONFLICT_ERROR}
{
  "error": { "code": "{CONFLICT_ERROR}", "message": "競合の詳細メッセージ" }
}
```
