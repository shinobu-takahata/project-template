## 4. 画面項目一覧

> **コンポーネント種別の凡例**
> `text-input` / `textarea` / `select` / `radio` / `checkbox` / `date-picker` /
> `button` / `link` / `label` / `table` / `image` / `icon`

| 項目ID | 項目名 | コンポーネント種別 | 必須/任意 | データ型 | 最大文字数 | 初期値 | 表示条件 | 活性/非活性条件 | バックエンド通信 |
|--------|--------|------------------|---------|---------|-----------|--------|---------|---------------|----------------|
| ITEM-001 | [項目名] | text-input | 必須 | string | 100 | （空） | 常時表示 | 常時活性 | なし |
| ITEM-002 | [項目名] | select | 必須 | string | - | （未選択） | 常時表示 | 常時活性 | あり（選択肢取得） |
| ITEM-003 | [項目名] | radio | 必須 | string | - | 選択肢A | 常時表示 | 常時活性 | なし |
| ITEM-004 | [項目名] | checkbox | 任意 | boolean | - | false | 常時表示 | 常時活性 | なし |
| ITEM-005 | [項目名] | textarea | 任意 | string | 500 | （空） | 常時表示 | 常時活性 | なし |
| ITEM-006 | [ボタン名] | button | - | - | - | - | 常時表示 | フォーム入力後に活性 | あり（データ送信） |
| ITEM-007 | キャンセル | button | - | - | - | - | 常時表示 | 常時活性 | なし |

> **表示条件の記述例**
> - `常時表示` : 常に表示する
> - `[ITEM-XXX] が "値A" のとき表示` : 他項目の値に連動する場合
> - `新規作成モードのみ表示` : 画面モードに依存する場合
>
> **活性/非活性条件の記述例**
> - `常時活性` : 常に操作可能
> - `[ITEM-XXX] が入力済みのとき活性` : 他項目の入力状態に連動する場合
> - `ローディング中は非活性` : 通信中に操作を禁止する場合
