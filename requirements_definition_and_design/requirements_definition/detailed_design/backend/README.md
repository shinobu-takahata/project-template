## 詳細設計書の書き方について
このディレクトリに配置されているテンプレートに沿って、以下のようなプロンプトを入力します。

```
@requirements_definition_and_design/requirements_definition/detailed_design/backend/detailed_design_template.md  

このドキュメントをもとに、アセスメント支援システムの以下のエンドポイントの以下のエンドポイントの詳細設計書を作成して。
「任意のURL」
```

このやり方に従うため、詳細設計書のインプットとなる情報が必要です。
インプットとなる情報は現状、主に以下となります。
- 業務フロー
- 機能要件定義書
- テーブル定義
- APIエンドポイント一覧
- ドメインモデル図
- 認証認可ドキュメント

## 実装のやり方について
plan_modeを選択した状態で以下のプロンプトを入力します。
```
@「その詳細設計書」
このドキュメントをもとに、backendの該当エンドポイントを作成して
```

内容に問題なさそうであれば実装を開始
